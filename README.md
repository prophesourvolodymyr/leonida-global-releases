# Leonida app downloads

Builds of the TheReal Leonida app: the live site at https://therealleonida.com in its own window, with native alerts.

| Platform | File | Notes |
|---|---|---|
| macOS | `Leonida_<version>_universal.dmg` | Apple silicon and Intel. Not notarized: the first time, right-click Leonida and choose Open, or run the command shown in the DMG window. |
| iOS | `Leonida_<version>.ipa` | Not signed. Install it with AltStore, SideStore or Sideloadly. There is no App Store version. |
| Windows, Linux | not built yet | |

The install guide with every step and each file's SHA-256 checksum is at https://therealleonida.com/app. Compare the checksum of your download with the one on that page.

The app loads only therealleonida.com. It does not run a wallet, and it does not update itself: a new version appears here and the site tells you when one is out.

TheReal Leonida is a fan project. It is not affiliated with Rockstar Games or Take-Two Interactive.
